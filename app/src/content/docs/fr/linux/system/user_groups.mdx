## Informations Utilisateurs et Groupes

> Les informations sur les **utilisateurs** et les **groupes** sont stockées dans les fichiers système suivants :

| Fichier/Dossier      | Description                                     |
| :------------------- | :---------------------------------------------- |
| `/etc/passwd`        | Informations de base sur les comptes utilisateurs. |
| `/etc/shadow`        | Mots de passe hachés des utilisateurs (accès restreint). |
| `/etc/group`         | Informations sur les groupes.                   |
| `/etc/gshadow`       | Mots de passe hachés des groupes (accès restreint). |

| Commande                       | Description                                                                                                                                                                                                                                                                                                                                       |
| :----------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `chage -l nom_utilisateur`     | Affiche les informations d'expiration du mot de passe d'un utilisateur.                                                                                                                                                                                                                                                                              |
| `groups`                       | Affiche les groupes auxquels appartient votre utilisateur.                                                                                                                                                                                                                                                                                            |
| `groups nom_utilisateur`       | Affiche les groupes auxquels appartient un autre utilisateur.                                                                                                                                                                                                                                                                                         |
| `compgen -u`                   | Liste tous les utilisateurs présents sur le système.                                                                                                                                                                                                                                                                                                  |
| `compgen -g`                   | Liste tous les groupes présents sur le système.                                                                                                                                                                                                                                                                                                       |
| `cut -d: -f1 /etc/passwd`      | Extrait et liste uniquement les noms d'utilisateur à partir du fichier `/etc/passwd`.                                                                                                                                                                                                                                                               |
| `cut -d: -f1 /etc/group`       | Extrait et liste uniquement les noms de groupe à partir du fichier `/etc/group`.                                                                                                                                                                                                                                                                    |
| `id`                           | Affiche l'identifiant numérique de l'utilisateur (**UID**), l'identifiant de groupe principal (**GID**) et les groupes secondaires auxquels appartient votre utilisateur.                                                                                                                                                                       |
| `id nom_utilisateur`           | Affiche les informations (UID, GID, groupes) d'un autre utilisateur.                                                                                                                                                                                                                                                                                  |
| `whoami`                       | Affiche le nom d'utilisateur effectif de la personne connectée.                                                                                                                                                                                                                                                                                       |

**Page de manuel associée :**

* `chage`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man1/chage.1.html)
* `groups`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man1/groups.1.html)
* `compgen`: [Voir man page (intégré à bash)](https://manpages.ubuntu.com/manpages/latest/man1/bash.1.html)
* `cut`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man1/cut.1.html)
* `id`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man1/id.1.html)
* `whoami`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man1/whoami.1.html)

## Gestion des Utilisateurs

| Commande                                   | Description                                                                                                                              |
| :----------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| `adduser nouvel_utilisateur`               | Ajoute un nouvel utilisateur au système de manière interactive (recommandé pour Debian/Ubuntu).                                          |
| `adduser nom_utilisateur nom_groupe`       | Ajoute un utilisateur existant à un groupe existant. L'utilisateur doit se déconnecter et se reconnecter pour que les changements prennent effet. |
| `useradd nom_utilisateur`                  | Commande non-interactive pour créer un utilisateur, souvent utilisée dans les scripts.                                                 |
| `deluser ancien_utilisateur`               | Supprime un utilisateur du système. Par défaut, le répertoire personnel n'est PAS supprimé.                                              |
| `deluser nom_utilisateur nom_groupe`       | Supprime un utilisateur d'un groupe spécifique.                                                                                          |
| `passwd`                                   | Modifie le mot de passe de l'utilisateur courant.                                                                                        |
| `passwd nom_utilisateur`                   | Modifie le mot de passe d'un autre utilisateur (nécessite `sudo`).                                                                     |
| `usermod --login nouveau_login ancien_login`| Change le nom d'utilisateur (le compte doit être inactif).                                                                             |
| `usermod -d /nouveau/chemin -m nom_utilisateur`| Change le répertoire personnel d'un utilisateur et déplace son contenu vers le nouveau chemin.                                         |

**Options spécifiques des commandes :**

* **`adduser` options :**
    | Option              | Description                                                                 |
    | :------------------ | :-------------------------------------------------------------------------- |
    | `--disabled-password` | Crée un utilisateur sans mot de passe, utile pour l'authentification par clé SSH uniquement. |
    | `--no-create-home`  | Empêche la création d'un répertoire personnel pour l'utilisateur.           |

* **`deluser` options :**
    | Option          | Description                                                                                             |
    | :-------------- | :------------------------------------------------------------------------------------------------------ |
    | `--remove-home` | Supprime l'utilisateur ET son répertoire personnel. **Attention : cette option utilise `rm -R` en arrière-plan, soyez extrêmement prudent !** |

* **`passwd` options :**
    | Option               | Description                                                                                     |
    | :------------------- | :---------------------------------------------------------------------------------------------- |
    | `-l nom_utilisateur` | Verrouille le mot de passe d'un utilisateur, désactivant la connexion par mot de passe (n'affecte pas la connexion par clé SSH). |
    | `-u nom_utilisateur` | Déverrouille le mot de passe d'un utilisateur.                                                  |
    | `-e nom_utilisateur` | Force l'utilisateur à changer de mot de passe lors de sa prochaine connexion.                   |
    | `-S nom_utilisateur` | Affiche le statut du mot de passe d'un utilisateur (verrouillé, sans mot de passe, utilisable, dates d'expiration, etc.). |

* **`usermod` options :**
    | Option                       | Description                                                                                 |
    | :--------------------------- | :------------------------------------------------------------------------------------------ |
    | `-G GROUPE1[,...]`           | Définit les groupes secondaires de l'utilisateur. **Attention : cette option remplace les groupes secondaires existants de l'utilisateur.** |
    | `-aG GROUPE1[,...]`          | **Ajoute** l'utilisateur aux groupes spécifiés sans le supprimer de ses groupes d'origine. |
    | `--expiredate AAAA-MM-JJ`    | Définit une date d'expiration pour le compte utilisateur. Utilisez `1` pour verrouiller le compte immédiatement, ou `""` (chaîne vide) pour déverrouiller. |

**Pages de manuel associées :**

* `adduser`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/adduser.8.html)
* `useradd`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/useradd.8.html)
* `deluser`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/deluser.8.html)

## Gestion des Groupes

| Commande                           | Description                                     |
| :--------------------------------- | :---------------------------------------------- |
| `addgroup nouveau_groupe`          | Ajoute un groupe au système de manière interactive. |
| `groupadd nom_groupe`              | Commande non-interactive pour créer un groupe, souvent utilisée dans les scripts. |
| `delgroup ancien_groupe`           | Supprime un groupe du système.                  |
| `groupmod --new-name nouveau_nom ancien_nom`| Modifie le nom d'un groupe existant.            |

**Pages de manuel associées :**

* `addgroup`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/addgroup.8.html)
* `groupadd`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/groupadd.8.html)
* `delgroup`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/delgroup.8.html)
* `groupmod`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/groupmod.8.html)
