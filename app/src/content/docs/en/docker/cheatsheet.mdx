## Docker container

### Create and run a new container from an image

The `docker run` command runs a command in a new container, pulling the image if needed and starting the container.

You can restart a stopped container with all its previous changes intact using `docker start`. Use `docker ps -a` to view a list of all containers, including those that are stopped.

Usage

<Code code={"docker run [OPTIONS] IMAGE [COMMAND] [ARG...]"} lang="bash" title={"Docker Run"} mark={highlights} />

Help

```bash
docker container run --help
```

Example, run latest debian image with an interactive console.
```bash
docker run -ti debian:latest
	Unable to find image 'debian:latest' locally
	latest: Pulling from library/debian
	60bdaf986dbe: Pull complete
	Digest: sha256:1aadfee8d292f64b045adb830f8a58bfacc15789ae5f489a0fedcd517a862cb9
	Status: Downloaded newer image for debian:latest

	root@db7509899198:/# id
		uid=0(root) gid=0(root) groups=0(root)
```

List all containers  including those that are stopped.

```bash
docker ps -a
	CONTAINER ID   IMAGE           COMMAND   CREATED         STATUS          PORTS     NAMES
	db7509899198   debian:latest   "bash"    7 minutes ago   Up 50 seconds             hungry_kalam
```

We can exit the interactive console and stop the container.

```bash
	root@db7509899198:/# exit
$ docker stop db7509899198
	db7509899198
$ docker start -i db7509899198
	root@db7509899198:/#
```


Now modify the container, by ading an empty file.

```bash
root@db7509899198:/# touch test.txt
```

We can get the diff from our actual container with original images

```bash
$ docker diff db7509899198
	A /test.txt
	C /root
	A /root/.bash_history
```

To create an image based on our container

```bash
$ docker commit db7509899198 debiantest
	sha256:fe731cbeff0446a10c288fc473fb3d18c2a5e5ac87703dc1f891cf6c5002d8a0
```

Now we can list all images, we can see our new image.

```bash
$ docker images
	REPOSITORY   TAG       IMAGE ID       CREATED          SIZE
	debiantest   latest    fe731cbeff04   59 seconds ago   158MB
	debian       latest    dc0de672ed12   2 weeks ago      139MB
```

Now we can export the image

```bash
$ docker save debiantest > ~/images/debiantest.tar
```

To delete the container

```bash
$ docker rm -f db7509899198
```

To delete the image
```bash
$ docker image remove fe731cbeff04
```
