## Información de Usuarios y Grupos

> La información sobre **usuarios** y **grupos** se almacena en los siguientes archivos del sistema:

| Archivo/Directorio   | Descripción                                   |
| :------------------- | :-------------------------------------------- |
| `/etc/passwd`        | Información básica de las cuentas de usuario. |
| `/etc/shadow`        | Contraseñas de usuario cifradas (acceso restringido). |
| `/etc/group`         | Información de los grupos.                    |
| `/etc/gshadow`       | Contraseñas de grupo cifradas (acceso restringido). |

| Comando                        | Descripción                                                                                                                                                                                                                                                                          |
| :----------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `chage -l nombre_usuario`      | Muestra la información de caducidad de la contraseña de un usuario.                                                                                                                                                                                                                   |
| `groups`                       | Muestra los grupos a los que pertenece tu usuario.                                                                                                                                                                                                                                   |
| `groups nombre_usuario`        | Muestra los grupos a los que pertenece otro usuario.                                                                                                                                                                                                                                 |
| `compgen -u`                   | Lista todos los usuarios presentes en el sistema.                                                                                                                                                                                                                                    |
| `compgen -g`                   | Lista todos los grupos presentes en el sistema.                                                                                                                                                                                                                                      |
| `cut -d: -f1 /etc/passwd`      | Extrae y lista solo los nombres de usuario del archivo `/etc/passwd`.                                                                                                                                                                                                                |
| `cut -d: -f1 /etc/group`       | Extrae y lista solo los nombres de grupo del archivo `/etc/group`.                                                                                                                                                                                                                   |
| `id`                           | Muestra el ID numérico del usuario (**UID**), el ID del grupo principal (**GID**) y los grupos secundarios a los que pertenece tu usuario.                                                                                                                                            |
| `id nombre_usuario`            | Muestra la información (UID, GID, grupos) de otro usuario.                                                                                                                                                                                                                           |
| `whoami`                       | Muestra el nombre de usuario efectivo de la persona actualmente conectada.                                                                                                                                                                                                           |

**Páginas de manual asociadas:**

* `chage`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man1/chage.1.html)
* `groups`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man1/groups.1.html)
* `compgen`: [Ver página de manual (integrado en bash)](https://manpages.ubuntu.com/manpages/latest/man1/bash.1.html)
* `cut`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man1/cut.1.html)
* `id`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man1/id.1.html)
* `whoami`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man1/whoami.1.html)

## Gestión de Usuarios

| Comando                                    | Descripción                                                                                                                            |
| :----------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| `adduser nuevo_usuario`                    | Agrega un nuevo usuario al sistema de forma interactiva (recomendado para distribuciones basadas en Debian/Ubuntu).                    |
| `adduser nombre_usuario nombre_grupo`      | Agrega un usuario existente a un grupo existente. El usuario debe cerrar y volver a iniciar sesión para que los cambios surtan efecto. |
| `useradd nombre_usuario`                   | Comando no interactivo para crear un usuario, a menudo utilizado en scripts de automatización.                                           |
| `deluser antiguo_usuario`                  | Elimina un usuario del sistema. Por defecto, el directorio personal del usuario NO se elimina.                                           |
| `deluser nombre_usuario nombre_grupo`      | Elimina un usuario de un grupo específico.                                                                                               |
| `passwd`                                   | Cambia la contraseña del usuario actual.                                                                                                 |
| `passwd nombre_usuario`                    | Cambia la contraseña de otro usuario (requiere `sudo`).                                                                                 |
| `usermod --login nuevo_login antiguo_login`| Cambia el nombre de usuario (la cuenta debe estar inactiva para esta operación).                                                         |
| `usermod -d /nueva/ruta -m nombre_usuario`| Cambia el directorio personal de un usuario y mueve su contenido a la nueva ruta.                                                        |

**Opciones específicas de comandos:**

* **Opciones de `adduser`:**
    | Opción              | Descripción                                                                  |
    | :------------------ | :--------------------------------------------------------------------------- |
    | `--disabled-password` | Crea un usuario sin contraseña, útil solo para autenticación por clave SSH. |
    | `--no-create-home`  | Impide la creación de un directorio personal para el usuario.                |

* **Opciones de `deluser`:**
    | Opción          | Descripción                                                                                             |
    | :-------------- | :------------------------------------------------------------------------------------------------------ |
    | `--remove-home` | Elimina el usuario Y su directorio personal. **Advertencia: ¡Esta opción usa `rm -R` en segundo plano, ten extrema precaución!** |

* **Opciones de `passwd`:**
    | Opción               | Descripción                                                                                     |
    | :------------------- | :---------------------------------------------------------------------------------------------- |
    | `-l nombre_usuario`  | Bloquea la contraseña de un usuario, deshabilitando el inicio de sesión por contraseña (no afecta el inicio de sesión por clave SSH si está configurado). |
    | `-u nombre_usuario`  | Desbloquea la contraseña de un usuario.                                                         |
    | `-e nombre_usuario`  | Fuerza al usuario a cambiar su contraseña en el próximo inicio de sesión.                       |
    | `-S nombre_usuario`  | Muestra el estado de la contraseña de un usuario (bloqueada, sin contraseña, utilizable, fechas de caducidad, etc.). |

* **Opciones de `usermod`:**
    | Opción                       | Descripción                                                                                 |
    | :--------------------------- | :------------------------------------------------------------------------------------------ |
    | `-G GRUPO1[,...]`            | Establece los grupos suplementarios del usuario. **Advertencia: ¡Esta opción reemplaza los grupos suplementarios existentes del usuario!** |
    | `-aG GRUPO1[,...]`           | **Agrega** al usuario a los grupos especificados sin eliminarlo de los grupos existentes. |
    | `--expiredate AAAA-MM-DD`    | Establece una fecha de caducidad para la cuenta de usuario. Usa `1` para bloquear la cuenta inmediatamente, o `""` (cadena vacía) para desbloquear. |

**Páginas de manual asociadas:**

* `useradd`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/useradd.8.html)
* `deluser`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/deluser.8.html)

## Gestión de Grupos

| Comando                            | Descripción                                     |
| :--------------------------------- | :---------------------------------------------- |
| `addgroup nuevo_grupo`             | Agrega un nuevo grupo al sistema de forma interactiva. |
| `groupadd nombre_grupo`            | Comando no interactivo para crear un grupo, a menudo utilizado en scripts. |
| `delgroup antiguo_grupo`           | Elimina un grupo del sistema.                   |
| `groupmod --new-name nuevo_nombre antiguo_nombre`| Cambia el nombre de un grupo existente.            |

**Páginas de manual asociadas:**

* `groupmod`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/groupmod.8.html)
