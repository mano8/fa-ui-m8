Full guide to use, setup and configure SSH

## Connect to SSH Server

| Command | Description |
|---------|-------------|
| `ssh SSH_USER@SSH_HOST` | Connect to ssh server SSH_HOST with user SSH_USER. |
| `ssh SSH_USER@SSH_HOST -P 2222` | Connect to ssh server SSH_HOST on port 2222. |
| `ssh -i ~/.ssh/MySshKeyName SSH_USER@SSH_HOST` | Connect to ssh server SSH_HOST with SSH key |

| Option | Description |
|---------|-------------|
| `-P` | Specify SSH server port |
| `-i` | Specify SSH private key file. |

## SSH keys

| Command | Description |
|---------|-------------|
| `ssh-keygen -t ed25519 -C "MyComment" -a 100 -f ~/.ssh/MySshKeyName` | Create secure SSH keys. |
| `ssh -i ~/.ssh/MySshKeyName SSH_USER@SSH_HOST` | Test SSH private key conexion. |
| `ssh-keygen -p -P <OldPassphrase> -N <NewPassphrase> -f <PrivateKey>` | Update SSH private key passphrase. |

### On Linux Client

| Command | Description |
|---------|-------------|
| `chmod 600 ~/.ssh/MySshKeyName` | Secure SSH private key. |
| `ls -alt ~/.ssh/MySshKeyName` | Verrify SSH private key permissions. |
| `ssh-copy-id -i ~/.ssh/MySshKeyName.pub <SSH_USER>@<SSH_HOST>` | Copy SSH public key to server `authorized_keys`. |

### On Windows Client

| Command | Description |
|---------|-------------|
| `Icacls $env:USERPROFILE\.ssh /c /t /Inheritance:d` | Remove ineritance from the `.ssh` folder. |
| `Icacls $env:USERPROFILE\.ssh\MySshKeyName /c /t /Remove:g "Tout le monde" Administrateurs System` | Secure SSH private key. |
| `Icacls $env:USERPROFILE\.ssh\MySshKeyName` | Verrify SSH private key permissions. |
| `type $env:USERPROFILE\.ssh\MySshKeyName.pub \| ssh <SSH_USER>@<SSH_HOST> "cat >> .ssh/authorized_keys"` | Copy SSH public key to server `authorized_keys`. |

### SSH logs

| Command | Description |
|---------|-------------|
| `sudo journalctl -u ssh` | Logs from ssh service journald. |
| `cat /var/log/auth.log` | Full Auth logs |
| `sudo fail2ban-client status sshd` | Fail2Ban SSH status. |
| `sudo grep "Failed password" /var/log/auth.log \| awk '{print $NF}' \| sort \| uniq -c \| sort -nr \| head` | Retrieve Failed conexion intents. |

## Send files over SSH with SCP

| Command | Description |
|---------|-------------|
| `scp <LocalFilePath> <sshUser>@<targetIP>:<TargetPath> -P <SshPort>` | Upload File from client to server. |
| `scp <sshUser>@<targetIP>:<RemoteFilePath> -p <SshPort> <LocalPath>` | Download file from server to client. |
| `scp <sshUser1>@<targetIP1>:<RemoteFilePath> <sshUser2>@<targetIP2>:<RemoteFilePath>` | To transfer file fom server1 to server2 directly. |
