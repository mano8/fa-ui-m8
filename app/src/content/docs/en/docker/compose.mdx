## Run Container

The `docker run` command runs a command in a new container, pulling the image if needed and starting the container.

<Card title="`docker run`" >
  | Command | Description |
  |---------|-------------|
  | `docker run -d -p 80:80 docker/getting-started` | Create and run a container in background. |
  | `docker run -it -p 8001:8080 --name my-nginx nginx` | Create and run a container in foreground. |
</Card>
- -> [documentation](https://docs.docker.com/reference/cli/docker/container/run/)
<Card title="Options">
  | Option | Description |
  |---------|-------------|
  | `-d` | Run the container in detached mode |
  | `-p 8001:8080` | Map port 8001 to port 8080 in the container |
  | `-it` | Interactive bash mode |
  | `--name` | Specify a custom identifier for a container |
  | `--rm` | Automatically remove the container and its associated anonymous volumes when it exits |
</Card>
<Card title="Examples">
  * Get current user id in Odoo docker container  
  ```bash
    sudo docker run --rm odoo:18.0 id odoo
  ```
</Card>



## Docker `ls`/`ps`

| Description | List containers |
|---------|-------------|
| Usage | `docker container ls [OPTIONS]`. |
| Aliases | `docker container list` `docker container ps` `docker ps` |

| Command | Description |
|---------|-------------|
| `docker ps` | List running containers. |
| `docker ps -a` | Show all containers (default shows just running). |
| `docker ps -s` | List running containers and Display total file sizes. |

- -> [documentation](https://docs.docker.com/reference/cli/docker/container/ls/)

## Docker `images`

| Description | List containers |
|---------|-------------|
| Usage | `docker image ls [OPTIONS] [REPOSITORY[:TAG]]`. |
| Aliases | `docker image list` `docker images` |


| Command | Description |
|---------|-------------|
| `docker images` | List all images. |
| `docker images -a` | Show all containers (default shows just running). |
| `docker images --tree` | List multi-platform images as a tree (EXPERIMENTAL). |

- -> [documentation](https://docs.docker.com/reference/cli/docker/image/ls/)
