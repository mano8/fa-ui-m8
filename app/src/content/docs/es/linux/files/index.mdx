Esta sección agrupa los comandos fundamentales para interactuar con el sistema de archivos de Linux.
En Linux, todo se trata como un archivo: ya sean documentos, programas, directorios o incluso periféricos.
Estos comandos permiten navegar por la estructura de directorios, manipular archivos y carpetas, y buscar información, todo directamente desde la línea de comandos.

## Gestión de Archivos y Directorios

### Listar el contenido de un directorio

| Comando | Descripción |
|---------|-------------|
| `ls` | Lista el contenido de un directorio. |
| `ls -l` | Muestra un formato largo incluyendo los permisos de acceso, el número de enlaces físicos, el propietario, el grupo, el tamaño en bytes y la fecha de última modificación. |
| `ls -a` | Incluye archivos y directorios ocultos. |
| `ls -t` | Ordena los archivos y directorios por fecha de modificación, del más reciente al más antiguo. |
| `ls -h` | Muestra el tamaño de los archivos en un formato legible. |
| `ls -lct` | Muestra los detalles, ordena por fecha de última modificación y utiliza el tiempo de la última modificación del estado para el orden. |
| `ls -1` | Lista un archivo o directorio por línea. |

> El comando `dir` es casi idéntico a `ls` con las mismas opciones, pero su visualización por defecto puede diferir ligeramente (por ejemplo, sin color por defecto, caracteres especiales escapados).

-> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/ls.1.html)

### Copiar/Mover/Eliminar

#### Mover/Renombrar

| Comando | Descripción |
|---------|-------------|
| `mv` | Mover o renombrar archivos y directorios. |

| Opción | Descripción |
|--------|-------------|
| `-f` | Fuerza la ejecución, sobrescribe los archivos de destino sin pedir confirmación. |
| `-i` | Pide confirmación antes de sobrescribir un archivo existente. |
| `-u` | Solo mueve o renombra el archivo si el archivo de origen es más reciente que el archivo de destino, o si el archivo de destino no existe. |

-> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/mv.1.html)

#### Copiar

| Comando | Descripción |
|---------|-------------|
| `cp` | Copiar archivos o directorios. |

| Opción | Descripción |
|--------|-------------|
| `-r` | Copia recursivamente, incluyendo los subdirectorios y todo su contenido. Esencial para copiar directorios. |
| `-a` | Modo archivo. Copia los archivos conservando tanto como sea posible los atributos originales. Muy útil para operaciones de respaldo. |
| `-i` | Pide confirmación antes de sobrescribir un archivo existente. |
| `-f` | Si el archivo de destino existe y no puede ser abierto, lo destruye y trata de crearlo de nuevo. |
| `-u` | Solo copia los archivos más recientes que su equivalente en el destino, o que no existen en el destino. |
| `-v` | Muestra un mensaje para cada archivo o directorio copiado (modo verboso). |

-> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/cp.1.html)

#### Eliminar

| Comando | Descripción |
|---------|-------------|
| `rm` | Eliminar archivos o directorios. |

| Opción | Descripción |
|--------|-------------|
| `-f` | Fuerza la ejecución, no pide confirmación antes de borrar, incluso si el archivo está protegido contra escritura. |
| `-r` | Borra recursivamente. Permite eliminar un directorio y todo su contenido (archivos y subdirectorios). Esencial para eliminar directorios no vacíos. |
| `-i` | Pide confirmación antes de borrar cada archivo. |

-> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/rm.1.html)

## Enlaces Físicos/Simbólicos

| Comando | Descripción |
|---------|-------------|
| `ln` | Crea un enlace a un archivo o directorio. |
| `ln -s Rep1/Rep2/Monfichier MonLien` | Crear un enlace simbólico llamado `MonLien` apuntando a `Rep1/Rep2/Monfichier`. |

| Opción | Descripción |
|--------|-------------|
| `-s` | Crea un enlace simbólico. |
| `-f` | Fuerza el sobrescribir el archivo de destino si ya existe. |
| `-d` | Permite al usuario `root` crear un enlace físico en un directorio. (Generalmente desaconsejado por razones de complejidad y potencial de bucles en el sistema de archivos). |

> Por defecto (sin la opción `-s`), `ln` crea un enlace físico. Un enlace físico es una entrada de directorio adicional para un mismo archivo. Los enlaces físicos no pueden apuntar a archivos en una partición diferente y no pueden apuntar a directorios (excepto con `-d` y para root, desaconsejado).
> Asegúrese de estar en el directorio donde desea crear el enlace, o especifique la ruta completa para el enlace (`link`).

-> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/ln.1.html)

## Creación y Escritura de Archivos

| Comando | Descripción |
|---------|-------------|
| `touch` | Crear archivos vacíos si no existen. Si el archivo ya existe, `touch` actualiza su marca de tiempo (fecha y hora de última modificación y acceso) a la hora actual, sin modificar su contenido. |
| `cat > archivo` | Redirige la entrada estándar hacia el archivo especificado. |
| `echo "texto" > archivo` | Crea un archivo con el `texto` especificado como contenido. |
| `echo "texto" >> archivo` | Añade el `texto` especificado al final de un archivo existente. |
| `tee` | Lee la entrada estándar y la escribe simultáneamente en la salida estándar y en uno o varios archivos. |

- -> [página del manual de touch](https://manpages.ubuntu.com/manpages/latest/man1/touch.1.html)
- -> [página del manual de cat](https://manpages.ubuntu.com/manpages/latest/man1/cat.1.html)
- -> [página del manual de echo](https://manpages.ubuntu.com/manpages/latest/man1/echo.1.html)
- -> [página del manual de tee](https://manpages.ubuntu.com/manpages/latest/man1/tee.1.html)

**Ejemplos:**

  ```bash
  # Sobrescribir un archivo del sistema (con sudo) y suprimir la visualización en la salida estándar
  echo "contenido importante" | sudo tee /ruta/hacia/archivo_sistema > /dev/null

  # Añadir múltiples líneas a un archivo del sistema (con sudo) usando un "documento aquí" (<< EOF)
  sudo tee -a /ruta/hacia/otro_archivo_sistema << EOF
  Línea 1
  Línea 2
  EOF

  # Con cat
  cat > nuevo_archivo.txt
  # Escriba su texto aquí
  # ...
  # Presione Ctrl+D para guardar y salir
  ```

## Búsqueda de Archivos y Contenido

### Con find

| Comando | Descripción |
|---------|-------------|
| `find` | Busca archivos y directorios en una jerarquía de directorios. |
| `find /var/log -name "*.log"` | Busca archivos con la extensión `.log` en el directorio `/var/log`. |
| `find /var/log -iname "MonFichier.log"` | Busca un archivo por nombre (insensible a mayúsculas). |
| `find /var/log -name "monfichier*" -type "f"` | Busca todos los archivos cuyo nombre comienza con `monfichier`. |
| `find /var/log -name "monfichier*" -user "root"` | Busca todos los archivos cuyo nombre comienza con `monfichier`, y cuyo propietario es `root`. |
| `find /var/log -name "monfichier*" -group "root"` | Busca todos los archivos cuyo nombre comienza con `monfichier`, y cuyo grupo es `root`. |
| `find . -mtime -1` | Busca archivos/directorios modificados hace menos de 1 día. |
| `find /ruta/hacia/directorio -name "*.old" -exec rm {} \;` | Elimina todos los archivos con la extensión `.old` del directorio `/ruta/hacia/directorio`. |
| `find /ruta/hacia/directorio -name "*.old" -ok rm {} \;` | Pide confirmación al usuario antes de ejecutar el comando. |

| Opción | Descripción |
|--------|-------------|
| `-name` | Busca por nombre de archivo/directorio (soporta caracteres comodín como `*` para cero o más caracteres, `?` para un solo carácter). |
| `-iname` | Busca un archivo/directorio por nombre (insensible a mayúsculas). |
| `-type` | Busca por tipo de archivo (`f`=archivo regular, `d`=directorio, `l`=enlace simbólico, etc.). |
| `-user` | Busca archivos/directorios pertenecientes a un usuario específico. |
| `-group` | Busca archivos/directorios pertenecientes a un grupo específico. |
| `-size +NC` | Busca archivos/directorios de un tamaño superior a `N` unidades. Las unidades comunes son `c` para bytes, `k` para Kio (kilobytes), `M` para Mio (megabytes), `G` para Gio (gigabytes). Por ejemplo, `+500k` significa más de 500 Kio. |
| `-mtime -N` | Busca archivos/directorios modificados hace menos de `N` días. (Ejemplo: `-1` para menos de un día, es decir, modificados hoy o ayer). |
| `-exec comando {} \;` | Ejecuta un `comando` para cada archivo encontrado. `{}` es un sustituto que será reemplazado por la ruta completa del archivo encontrado. El `;` final debe ser escapado (`\;`). |
| `-ok comando {} \;` | Similar a `-exec`, pero pide confirmación al usuario antes de ejecutar el comando para cada archivo. |

- -> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/find.1.html)

### Con grep

| Comando | Descripción |
|---------|-------------|
| `grep` | Busca una cadena de caracteres en archivos o la entrada estándar. |
| `grep "cadena_buscada" archivo.txt` | Para buscar una cadena en un archivo. |
| `grep -rl "cadena_buscada" /ruta/hacia/directorio/` | Para buscar una cadena en varios archivos recursivamente en `/ruta/hacia/directorio/` y mostrar solo los nombres de los archivos correspondientes. |
| `grep "modelo1\|modelo2" archivo` | Busca las líneas que contienen uno u otro modelo (operador lógico OR). |
| `ps aux | grep -i "firefox"` | Filtra la salida de un `comando` para mostrar solo las líneas que contienen el "modelo" especificado. |

| Opción | Descripción |
|--------|-------------|
| `-r` | Busca recursivamente en los subdirectorios. (El comando `rgrep` es un alias común para `grep -r`). |
| `-l` | Muestra solo los nombres de los archivos correspondientes. |
| `-i` | Busca insensible a mayúsculas. |
| `-n` | Muestra el número de línea para cada coincidencia encontrada. |
| `-c` | Muestra el número de líneas correspondientes en cada archivo. |
| `-v` | Invierte la búsqueda; muestra las líneas que *no* coinciden con el modelo. |
| `-A N` | Muestra las `N` líneas *después* de cada coincidencia. |
| `-B N` | Muestra las `N` líneas *antes* de cada coincidencia. |
| `-C N` | Muestra las `N` líneas *alrededor* de cada coincidencia (`-A N -B N`). |

- -> [página del manual](https://manpages.ubuntu.com/manpages/latest/man1/grep.1.html)

### Con locate

| Comando | Descripción |
|---------|-------------|
| `locate` | Encuentra rápidamente archivos usando una base de datos pre-indexada del sistema de archivos. |
| `sudo updatedb` | Actualiza la base de datos. |

- -> [página del manual de locate](https://manpages.ubuntu.com/manpages/latest/man1/locate.1.html)

## Abrir un Directorio en el Gestor de Archivos Gráfico

| Comando | Descripción |
|---------|-------------|
| `xdg-open .` | Abre el directorio actual en el gestor de archivos gráfico por defecto. |
