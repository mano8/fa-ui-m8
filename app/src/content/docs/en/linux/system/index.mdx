## Keyboard Shortcuts (Terminal)

| Shortcut | Description |
|---------|-------------|
| **`Ctrl+Alt+T`**| Opens a new terminal.
| **`Ctrl+C`**| Interrupts the current process (`SIGINT`, "polite" stop). |
| **`Ctrl+Z`**| Suspends the current process (`SIGTSTP`, can be resumed with `fg` or `bg`). |
| **`Ctrl+D`**| Signals the end of input (equivalent to `exit` if the terminal is empty). |
| **`Ctrl+L`**| Clears the screen (equivalent to `clear`). |
| **`Ctrl+W`**| Deletes the word before the cursor. |
| **`Ctrl+U`**| Deletes the entire line before the cursor. |
| **`Ctrl+R`**| Searches through the command history. |
| **`!!`**| Repeats the last command. |
| **Command History**| Use the Up/Down arrows to navigate through previous commands. |

### Network

| Command | Description |
|---------|-------------|
| `hostnamectl` | Displays hostname information |
| `hostname` | To display system hostname. |
| `hostname -i` | To display system IP address |
| `ip a` | List IP addresses and network interfaces. |
| `ping [remote_host]` | Ping remote host. |
| `netstat -tulpn` | See active ports. |
| `netstat -tulpn | grep LISTEN` | See active listening ports. |
| `netstat -tulpn | grep ':443'` | See active listening services on port 443. |
| `netstat -tuln` | Show TCP and UDP ports and their programs. |
| `sudo ss -tulw` | See active listening ports. |
| `sudo ss -tulpn` | See active listening ports. |
| `sudo ss -tulpn | grep LISTEN` | See active listening ports. |
| `sudo lsof -i -U` | To list all open Internet, x.25 (HP-UX), and UNIX domain files. |
| `sudo lsof -i 4 -U` | To list all open IPv4 network files. |
| `sudo lsof -i 6 -U` | To list all open IPv6 network files. |
| `sudo lsof -i -P -n` | See active ports. |
| `sudo lsof -i -P -n | grep LISTEN` | See active listening ports. |
| `whois [domain_name]` | Display more information about a domain. |
| `dig [domain_name]` | 	Show DNS information about a domain. |
| `dig -x [domain_name]` | Do a reverse DNS lookup on the domain. |
| `dig -x [IP_address]` | Do a reverse DNS lookup of an IP address. |
| `host [domain_name]` | Perform an IP lookup for a domain. |
| `nslookup [domain_name]` | Receive information about a domain. |

---

* **`netstat`**:

  | Option | Description |
  |--------|-------------|
  | `-t` | Select all TCP ports |
  | `-u` | Select all UDP ports |
  | `-l` | Show listening server sockets (open TCP and UDP ports in listing state) |
  | `-p` | Display PID/Program name for sockets. In other words, this option tells who opened the TCP or UDP port. For example, on my system, Nginx opened TCP port 80/443, so I will /usr/sbin/nginx or its PID. |
  | `-n` | Don’t resolve name (avoid dns lookup, this speed up the netstat on busy Linux/Unix servers) |

  - -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/netstat.8.html)
  
  > The netstat is mostly obsolete.  Replacement for netstat is `ss`.

* **`ss`**:

  | Option | Description |
  |--------|-------------|
  | `-t` | Show only TCP sockets |
  | `-u` | Display only UDP sockets |
  | `-l` | Show listening sockets. For example, TCP port 22 is opened by SSHD server. |
  | `-w` | Display RAW sockets. |
  | `-p` | Show process using socket. |
  | `-n` | Don’t resolve service names i.e. don’t use DNS. |

  - -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/ss.8.html)

* **`lsof`**:

  | Option | Description |
  |--------|-------------|
  | `-i` | Selects the listing of all network files (If no Ip specified) |
  | `-P` | Inhibits the conversion of port numbers to port names for network files |
  | `-n` | Inhibits the conversion of network numbers to host names for network files. |
  | `-U` | Selects the listing of UNIX domain socket files. |


  - -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/lsof.8.html)

### Cron Jobs

Manages scheduled tasks (cron jobs) for a user.

#### Directories

  Cron jobs are located in the spool directories, in tables called crontabs.  
  Their location varies across different distributions, here we focus in Debian/Ubuntu systems.

  | Location | Description |
  |---------|-------------|
  | `/etc/crontab` | Cron jobs location for `root` user  |
  | `/var/spool/cron/crontabs` | Cron jobs location for other users  |

#### Listing Cron Jobs

  | Command | Description |
  |---------|-------------|
  | `sudo cat /etc/crontab` | List of Cron jobs for `root` user |
  | `sudo cat /var/spool/cron/crontabs` | List of Cron jobs for other users |
  | `crontab -l` | List All Active Cron Jobs for the current user |
  | `sudo crontab -u [username] -l` | List All Active Cron Jobs by user |
  | `sudo crontab -u [username] -l` | List All Active Cron Jobs by user |
  | `ls -la /etc/cron.hourly` | List Hourly Cron Jobs for the current user |
  | `ls -la /etc/cron.daily` | List Daily Cron Jobs for the current user |
  | `ls -la /etc/cron.weekly` | List Weekly Cron Jobs for the current user |
  | `ls -la /etc/cron.monthly` | List Monthly Cron Jobs for the current user |
  | `ls -l /etc/cron.d` | View Software-Specific Cron Jobs |

## System Management

### Process Management

To manage, and stop ongoing processes:

| Command | Description |
|---------|-------------|
| `kill 5678` | To stop a process gracefully by its ID (PID). |
| `kill -9 5678` | To force stop a process by its ID (PID). |
| `killall firefox` | To stop all 'firefox' processes |
| `sudo pkill -u username` | To stop all processes of a user |
| `bg` | List and resume stopped jobs in the background. |
| `fg` | Brings the last backgrounded process to the foreground. |
| `fg [job]` | Bring a particular job to the foreground. |
| `wait` | Pause the terminal or a Bash script until a running process is completed. |
| `nohup [command] &` | Run a Linux process in the background. |

### Package Management

To install, remove, and manage software (packages):

* **`apt` / `apt-get`**: Package management tool for Debian-based distributions (like Ubuntu).

  | Command | Description |
  |---------|-------------|
  | `sudo apt update` | To update the list of available packages |
  | `sudo apt upgrade` | To upgrade all installed packages |
  | `sudo apt install package_name` | To install a package |
  | `sudo apt-get install -y package_name ` | To install a package, assume "yes" as answer to all prompts and run non-interactively |
  | `sudo apt-get install -s package_name ` | Perform a simulation of events that would occur based on the current system state. |
  | `sudo apt-get install -f package_name ` | Attempt to correct a system with broken dependencies in place. |
  | `sudo apt-get install --no-install-recommends package_name ` | Do not consider recommended packages as a dependency for installing. |
  | `sudo apt remove package_name` | To remove a package |
  | `sudo apt --purge remove package_name` | To remove a package and its configuration files |
  | `sudo apt purge package_name` | To remove a package and its configuration files |
  | `sudo apt clean` | Clean deb package cache from system. |
  | `sudo apt list` | List packages installed with APT. |
  | `sudo apt show [package_name]` | Show information about a package. |

  - -> [`apt` man page](https://https://manpages.ubuntu.com/manpages/questing/en/man8/apt.8.html)
  - -> [`apt-get` man page](https://manpages.ubuntu.com/manpages/questing/en/man8/apt-get.8.html)

* **`apt-cache`**: Tool to query the APT package cache.

  | Command | Description |
  |---------|-------------|
  | `apt-cache search keyword` | To search for a package by name or description |
  | `apt-cache show package_name` | To display detailed information about a package |

  - -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/apt-cache.8.html)

### Service Management

System services are managed by an initialization system (`init system`), often `systemd` on Ubuntu.

* **`systemctl`**: Used to control and query the state of system services under `systemd`.

| Command | Description |
|---------|-------------|
| `sudo systemctl reboot` | To reboot the server |
| `sudo systemctl poweroff` | To power off the server |
| `sudo systemctl rescue` | Rescue mode |
| `sudo systemctl start {servicename}` | To start a service |
| `sudo systemctl restart {servicename}` | To restart a service |
| `sudo systemctl stop {servicename}` | To stop a service |
| `sudo systemctl status {servicename}` | To display the status of a service |
| `sudo systemctl is-active {servicename}` | To check if a service is active |
| `sudo systemctl is-enabled {servicename}` | To check if a service is enabled (at startup) |
| `sudo systemctl list-units --type=service` | To display the status of all services |
| `sudo systemctl list-units --type=service --state=active` | To display the status of all active services |
| `sudo systemctl enable {servicename}` | To enable a service to start at boot |
| `sudo systemctl disable {servicename}` | To disable a service |
| `sudo systemctl mask {servicename}` | To prevent a service from starting |
| `sudo systemctl kill {servicename}` | To stop a service |
| `sudo systemctl kill -s 9 {servicename}` | To force stop a service |
| `sudo systemd-analyze` | Analyze |
| `sudo systemd-analyze blame` | System boot time |

  - -> [`systemctl` man page](https://manpages.ubuntu.com/manpages/questing/en/man1/systemctl.1.html)
  - -> [`systemd-analyze` man page](https://manpages.ubuntu.com/manpages/questing/en/man1/systemd-analyze.1.html)

### Mount disks

| Command | Description |
|---------|-------------|
| `mount` | Displays mounted filesystems. |
| `mount device mount_point` | Mounts a filesystem |
| `umount mount_point` | Unmounts a filesystem by mount_point |
| `umount device` | Unmounts a filesystem by device |

- -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/mount.8.html)

* **`umount`**:

  | Option | Description |
  |--------|-------------|
  | `-f` | Forces unmount (dangerous) |

  - -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man2/umount.2.html)

#### Example

  <div className='fd-steps [&_h3]:fd-step'>
    1. Create mount point directory
    ```
    mkdir /media/usb-drive
    ```
  </div>

  <div className='fd-steps [&_h3]:fd-step'>
    2. Find the USB device and file system type. Run:
    ```
    fdisk -l
    ```
  </div>

  <div className='fd-steps [&_h3]:fd-step'>
    3. Using the device identifier from fdisk output run:
    > for example, if the device is listed as `/dev/sdb1`
    ```
    sudo mount /dev/sdb1 /media/usb-drive
    ```
  </div>

### System Directories

* **`/run` and `/var/run`**: Directory for temporary files created at boot or by services.
* **`/etc/default/`**: Directory containing configuration files for variables used by initialization scripts (`init.d`).
* **Reboot required**: A signaling file `/run/reboot-required` is created when the system requires a reboot.
