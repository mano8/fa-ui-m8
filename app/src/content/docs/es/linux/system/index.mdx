* **`netstat`**:

    | Opción | Descripción                                                                                                                                                                             |
    | :----- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `-t`   | Selecciona todos los puertos TCP.                                                                                                                                                       |
    | `-u`   | Selecciona todos los puertos UDP.                                                                                                                                                       |
    | `-l`   | Muestra los sockets de servidor en escucha (puertos TCP y UDP abiertos en estado de escucha).                                                                                         |
    | `-p`   | Muestra el PID/nombre del programa para los sockets. En otras palabras, esta opción indica quién abrió el puerto TCP o UDP. Por ejemplo, en mi sistema, Nginx abrió el puerto TCP 80/443, por lo que se mostrará `/usr/sbin/nginx` o su PID. |
    | `-n`   | No resuelve nombres (evita la búsqueda DNS, lo que acelera `netstat` en servidores Linux/Unix ocupados).                                                                              |

    ---
    -> [página man](https://manpages.ubuntu.com/manpages/questing/en/man8/netstat.8.html)

    > `netstat` está mayormente obsoleto. El reemplazo de `netstat` es `ss`.

* **`ss`**:

    | Opción | Descripción                                      |
    | :----- | :----------------------------------------------- |
    | `-t`   | Muestra solo sockets TCP.                        |
    | `-u`   | Muestra solo sockets UDP.                        |
    | `-l`   | Muestra los sockets en escucha. Por ejemplo, el puerto TCP 22 es abierto por el servidor SSHD. |
    | `-w`   | Muestra sockets RAW.                             |
    | `-p`   | Muestra el proceso que usa el socket.            |
    | `-n`   | No resuelve nombres de servicio (es decir, no usa DNS). |

    ---
    -> [página man](https://manpages.ubuntu.com/manpages/questing/en/man8/ss.8.html)

* **`lsof`**:

    | Opción | Descripción                                              |
    | :----- | :------------------------------------------------------- |
    | `-i`   | Selecciona la lista de todos los archivos de red (si no se especifica una IP). |
    | `-P`   | Inhibe la conversión de números de puerto a nombres de puerto para archivos de red. |
    | `-n`   | Inhibe la conversión de números de red a nombres de host para archivos de red. |
    | `-U`   | Selecciona la lista de archivos de socket de dominio UNIX. |

    ---
    -> [página man](https://manpages.ubuntu.com/manpages/questing/en/man8/lsof.8.html)

### Tareas Cron

Administra las tareas programadas (tareas cron) para un usuario.

#### Directorios

Las tareas cron se encuentran en los directorios spool, en tablas llamadas `crontabs`. Su ubicación varía entre diferentes distribuciones; aquí nos centramos en los sistemas Debian/Ubuntu.

| Ubicación                    | Descripción                               |
| :--------------------------- | :---------------------------------------- |
| `/etc/crontab`               | Ubicación de las tareas cron para el usuario `root`. |
| `/var/spool/cron/crontabs`   | Ubicación de las tareas cron para otros usuarios. |

#### Listar Tareas Cron

| Comando                              | Descripción                                      |
| :----------------------------------- | :----------------------------------------------- |
| `sudo cat /etc/crontab`              | Lista las tareas Cron para el usuario `root`.    |
| `sudo cat /var/spool/cron/crontabs`  | Lista las tareas Cron para otros usuarios.       |
| `crontab -l`                         | Lista todas las tareas Cron activas para el usuario actual. |
| `sudo crontab -u [username] -l`      | Lista todas las tareas Cron activas por usuario. |
| `ls -la /etc/cron.hourly`            | Lista las tareas Cron por hora.                  |
| `ls -la /etc/cron.daily`             | Lista las tareas Cron diarias.                   |
| `ls -la /etc/cron.weekly`            | Lista las tareas Cron semanales.                 |
| `ls -la /etc/cron.monthly`           | Lista las tareas Cron mensuales.                 |
| `ls -l /etc/cron.d`                  | Muestra las tareas Cron específicas del software. |

### Gestión de Servicios

Los servicios del sistema son gestionados por un sistema de inicialización (`init system`), a menudo `systemd` en Ubuntu.

* **`systemctl`**: Usado para controlar y consultar el estado de los servicios del sistema bajo `systemd`.

| Comando                                     | Descripción                                       |
| :------------------------------------------ | :------------------------------------------------ |
| `sudo systemctl reboot`                     | Reinicia el servidor.                             |
| `sudo systemctl poweroff`                   | Apaga el servidor.                                |
| `sudo systemctl rescue`                     | Entra en modo de rescate.                         |
| `sudo systemctl start {servicename}`        | Inicia un servicio.                               |
| `sudo systemctl restart {servicename}`      | Reinicia un servicio.                             |
| `sudo systemctl stop {servicename}`         | Detiene un servicio.                              |
| `sudo systemctl status {servicename}`       | Muestra el estado de un servicio.                 |
| `sudo systemctl is-active {servicename}`    | Comprueba si un servicio está activo.             |
| `sudo systemctl is-enabled {servicename}`   | Comprueba si un servicio está habilitado (al inicio). |
| `sudo systemctl list-units --type=service`  | Muestra el estado de todos los servicios.         |
| `sudo systemctl list-units --type=service --state=active` | Muestra el estado de todos los servicios activos. |
| `sudo systemctl enable {servicename}`       | Habilita un servicio para que se inicie al arrancar. |
| `sudo systemctl disable {servicename}`      | Deshabilita un servicio.                          |
| `sudo systemctl mask {servicename}`         | Impide que un servicio se inicie.                 |
| `sudo systemctl kill {servicename}`         | Detiene un servicio.                              |
| `sudo systemctl kill -s 9 {servicename}`    | Fuerza la detención de un servicio.               |
| `sudo systemd-analyze`                      | Analiza el rendimiento del arranque del sistema.  |
| `sudo systemd-analyze blame`                | Muestra el desglose del tiempo de arranque del sistema por servicio. |

## Directorios del Sistema

* **`/run` y `/var/run`**: Directorio para archivos temporales creados al inicio o por los servicios.
* **`/etc/default/`**: Directorio que contiene archivos de configuración para las variables utilizadas por los scripts de inicialización (`init.d`).
* **Reinicio necesario**: Se crea un archivo de señalización `/run/reboot-required` cuando el sistema necesita un reinicio.
