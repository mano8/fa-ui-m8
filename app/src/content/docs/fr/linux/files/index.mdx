Cette section regroupe les commandes fondamentales pour interagir avec le système de fichiers Linux.
En Linux, tout est traité comme un fichier : qu'il s'agisse de documents, de programmes, de répertoires ou même de périphériques.
Ces commandes permettent de naviguer dans l'arborescence, de manipuler des fichiers et des dossiers, et de rechercher des informations, le tout directement depuis la ligne de commande.

## Gestion de Fichiers et Répertoires

### Liste le contenu d'un dossier (répertoire)

| Commande | Description |
|----------|-------------|
| `ls` | Liste le contenu d'un dossier (répertoire). |
| `ls -l` | Affiche un format long incluant les permissions d'accès, le nombre de liens physiques, le propriétaire, le groupe, la taille en octets et la date de dernière modification. |
| `ls -a` | Inclut les fichiers et répertoires cachés. |
| `ls -t` | Trie les fichiers et répertoires par date de modification, du plus récent au plus ancien. |
| `ls -h` | Affiche la taille des fichiers dans un format lisible. |
| `ls -lct` | Affiche les détails, trie par date de dernière modification, et utilise le temps de la dernière modification du statut pour le tri. |
| `ls -1` | Liste un fichier ou répertoire par ligne. |

> La commande `dir` est quasi identique à `ls` avec les mêmes options, mais son affichage par défaut peut légèrement différer (par exemple, pas de couleur par défaut, caractères spéciaux échappés).

-> [man page](https://manpages.ubuntu.com/manpages/latest/man1/ls.1.html)

### Copier/Déplacer/Supprimer

#### Déplacer/Renommer

| Commande | Description |
|----------|-------------|
| `mv` | Déplacer ou renommer des fichiers et des répertoires. |

| Option | Description |
|--------|-------------|
| `-f` | Force l'exécution, écrase les fichiers de destination sans demander de confirmation. |
| `-i` | Demande confirmation avant d'écraser un fichier existant. |
| `-u` | Ne déplace ou ne renomme le fichier que si le fichier source est plus récent que le fichier de destination, ou si le fichier de destination n'existe pas. |

-> [man page](https://manpages.ubuntu.com/manpages/latest/man1/mv.1.html)

#### Copier

| Commande | Description |
|----------|-------------|
| `cp` | Copier des fichiers ou des répertoires. |

| Option | Description |
|--------|-------------|
| `-r` | Copie récursivement, y compris les sous-répertoires et tout leur contenu. Essentiel pour copier des répertoires. |
| `-a` | Mode archive. Copie les fichiers en conservant autant que possible les attributs originaux. Très utile pour les opérations de sauvegarde. |
| `-i` | Demande une confirmation avant d'écraser un fichier existant. |
| `-f` | Si le fichier de destination existe et ne peut être ouvert, le détruit et essaie de le créer à nouveau. |
| `-u` | Ne copie que les fichiers plus récents que leur équivalent dans la destination, ou qui n'existent pas dans la destination. |
| `-v` | Affiche un message pour chaque fichier ou répertoire copié (mode verbeux). |

-> [man page](https://manpages.ubuntu.com/manpages/latest/man1/cp.1.html)

#### Supprimer

| Commande | Description |
|----------|-------------|
| `rm` | Supprimer des fichiers ou des répertoires. |

| Option | Description |
|--------|-------------|
| `-f` | Force l'exécution, ne demande pas de confirmation avant d'effacer, même si le fichier est protégé en écriture. |
| `-r` | Efface récursivement. Permet de supprimer un répertoire et tout son contenu (fichiers et sous-répertoires). Essentiel pour supprimer des répertoires non vides. |
| `-i` | Demande une confirmation avant d'effacer chaque fichier. |

-> [man page](https://manpages.ubuntu.com/manpages/latest/man1/rm.1.html)

## Liens physiques/symboliques

| Commande | Description |
|----------|-------------|
| `ln` | Crée un lien vers un fichier ou un répertoire. |
| `ln -s Rep1/Rep2/Monfichier MonLien` | Créer un lien symbolique nommé `MonLien` pointant vers `Rep1/Rep2/Monfichier`. |

| Option | Description |
|--------|-------------|
| `-s` | Crée un lien symbolique. |
| `-f` | Force l'écrasement du fichier de destination s'il existe déjà. |
| `-d` | Permet à l'utilisateur `root` de créer un lien physique sur un répertoire. |

> Par défaut (sans l'option `-s`), `ln` crée un lien physique. Un lien physique est une entrée de répertoire supplémentaire pour un même fichier. Les liens physiques ne peuvent pas pointer vers des fichiers sur une partition différente et ne peuvent pas pointer vers des répertoires (sauf avec `-d` et pour root, déconseillé).
> Assurez-vous de vous trouver dans le répertoire où vous souhaitez créer le lien, ou spécifiez le chemin complet pour le lien (`link`).

-> [man page](https://manpages.ubuntu.com/manpages/latest/man1/ln.1.html)

## Création et Écriture de Fichiers

| Commande | Description |
|----------|-------------|
| `touch` | Créer des fichiers vides s'ils n'existent pas. Si le fichier existe déjà, `touch` met à jour son horodatage (date et heure de dernière modification et d'accès) à l'heure actuelle, sans modifier son contenu. |
| `cat > fichier` | Redirige l'entrée standard vers le fichier spécifié. |
| `echo "texte" > fichier` | Crée un fichier avec le texte spécifié comme contenu. |
| `echo "texte" >> fichier` | Ajoute le texte spécifié à la fin d'un fichier existant. |
| `tee` | Lit l'entrée standard et l'écrit simultanément sur la sortie standard et dans un ou plusieurs fichiers. |

- -> [`touch` man page](https://manpages.ubuntu.com/manpages/latest/man1/touch.1.html)
- -> [`cat` man page](https://manpages.ubuntu.com/manpages/latest/man1/cat.1.html)
- -> [`echo` man page](https://manpages.ubuntu.com/manpages/latest/man1/echo.1.html)
- -> [`tee` man page](https://manpages.ubuntu.com/manpages/latest/man1/tee.1.html)

**Exemples :**
  
  ```bash
  # Écraser un fichier système (avec sudo) et supprimer l'affichage sur la sortie standard
  echo "contenu important"   sudo tee /chemin/vers/fichier_systeme > /dev/null

  # Ajouter plusieurs lignes à un fichier système (avec sudo) en utilisant un "here document" (<< EOF)
  sudo tee -a /chemin/vers/autre_fichier_systeme << EOF
  Ligne 1
  Ligne 2
  EOF

  # Avec cat
  cat > nouveau_fichier.txt
  # Saisissez votre texte ici
  # ...
  # Appuyez sur Ctrl+D pour enregistrer et quitter
  ```

## Affichage de Fichiers

| Commande | Description |
|----------|-------------|
| `head` | Affiche les premières lignes d'un fichier. (par défaut les 10 premières lignes) |
| `cat` | Affiche le contenu complet d'un ou plusieurs fichiers texte. |
| `cat -n` | Affiche le contenu du fichier avec les numéros de ligne. |
| `tail` | Affiche les dernières lignes d'un fichier. (par défaut les 10 premières lignes) |
| `tail -n 20 fichier.log` | Pour afficher les 20 dernières lignes d'un fichier. |
| `tail -f fichier.log` | Pour afficher le contenu d'un fichier en temps réel au fur et à mesure qu'il est ajouté (utile pour les fichiers de log qui sont mis à jour en continu). |
| `more` | Affiche le contenu d'un fichier page par page. (par défaut les 10 premières lignes) |
| `less` | Permet de parcourir un fichier page par page avec des capacités de navigation et de recherche plus avancées. |

- -> [`head` man page](https://manpages.ubuntu.com/manpages/latest/man1/head.1.html)

- -> [`tail` man page](https://manpages.ubuntu.com/manpages/latest/man1/tail.1.html)
- -> [`more` man page](https://manpages.ubuntu.com/manpages/latest/man1/more.1.html)
- -> [`less` man page](https://manpages.ubuntu.com/manpages/latest/man1/less.1.html)


## Recherche de Fichiers et Contenu

### Avec find

| Commande | Description |
|----------|-------------|
| `find` | Recherche des fichiers et répertoires dans une hiérarchie de répertoires. |
| `find /var/log -name "*.log"` | Recherche les fichiers avec l'extension `.log` dans le répertoire `/var/log`. |
| `find /var/log -iname "MonFichier.log"` | Recherche un fichier par nom (insensible à la casse). |
| `find /var/log -name "monfichier*" -type "f"` | Recherche tous les fichiers dont le nom commence par `monfichier`. |
| `find /var/log -name "monfichier*" -user "root"` | Recherche tous les fichiers dont le nom commence par `monfichier`, et dont le propriétaire est `root`. |
| `find /var/log -name "monfichier*" -group "root"` | Recherche tous les fichiers dont le nom commence par `monfichier`, et dont le groupe est `root`. |
| `find . -mtime -1` | Recherche les fichiers/repertoires modifiés il y a moins de 1 jours. |
| `find /chemin/vers/dossier -name "*.old" -exec rm {} \;` | Supprime tous les fichiers avec l'extension `.old` du repertoire `/chemin/vers/dossier`. |
| `find /chemin/vers/dossier -name "*.old" -ok rm {} \;` | Demande une confirmation à l'utilisateur avant d'exécuter la commande. |


| Option | Description |
|--------|-------------|
| `-name` | Recherche par nom de fichier/repertoire (supporte les caractères génériques ou "jokers" comme `*` pour zéro ou plusieurs caractères, `?` pour un seul caractère). |
| `-iname` | Recherche un fichier/repertoire par nom (insensible à la casse). |
| `-type` | Recherche par type de fichier (`f`=fichier régulier, `d`=répertoire, `l`=lien symbolique, etc.) |
| `-user` | Recherche les fichiers/repertoires appartenant à un utilisateur spécifique. |
| `-group` | Recherche les fichiers/repertoires appartenant à un groupe spécifique. |
| `-size +NC` | Recherche les fichiers/repertoires d'une taille supérieure à `N` unités. Les unités courantes sont `c` pour octets, `k` pour Kio (kilooctets), `M` pour Mio (mégaoctets), `G` pour Gio (gigaoctets). Par exemple, `+500k` signifie plus de 500 Kio. |
| `-mtime -N` | Recherche les fichiers/repertoires modifiés il y a moins de `N` jours. (Exemple : `-1` pour moins d'un jour, c'est-à-dire modifiés aujourd'hui ou hier). |
| `-exec commande {} \;` | Exécute une `commande` pour chaque fichier trouvé. `{}` est un substitut qui sera remplacé par le chemin complet du fichier trouvé. Le `;` final doit être échappé (`\;`). |
| `-ok commande {} \;` | Similaire à `-exec`, mais demande une confirmation à l'utilisateur avant d'exécuter la commande pour chaque fichier. |

- -> [man page](https://manpages.ubuntu.com/manpages/latest/man1/find.1.html)

### Avec grep

| Commande | Description |
|----------|-------------|
| `grep` | Recherche une chaîne de caractères dans des fichiers ou l'entrée standard. |
| `grep "chaine_recherchee" fichier.txt` | Pour chercher une chaîne dans un fichier. |
| `grep -rl "chaine_recherchee" /chemin/vers/dossier/` | Pour chercher une chaîne dans plusieurs fichiers recursivement dans `/chemin/vers/dossier/` et afficher uniquement les noms des fichiers correspondants. |
| `grep "modèle1\|modèle2" fichier` | Recherche les lignes contenant l'un ou l'autre modèle (opérateur logique OR) |
| `ps aux | grep -i "firefox"` | Filtre la sortie d'une `commande` pour n'afficher que les lignes contenant le "modèle" spécifié. |

| Option | Description |
|--------|-------------|
| `-r` | Recherche récursivement dans les sous-répertoires. (La commande `rgrep` est un alias commun pour `grep -r`). |
| `-l` | Affiche uniquement les noms des fichiers correspondants. |
| `-i` | Recherche insensible à la casse. |
| `-n` | Affiche le numéro de ligne pour chaque correspondance trouvée. |
| `-c` | Affiche le nombre de lignes correspondantes dans chaque fichier. |
| `-v` | Inverse la recherche. affiche les lignes *ne* correspondant *pas* au modèle. |
| `-A N` | Affiche les `N` lignes *après* chaque correspondance. |
| `-B N` | Affiche les `N` lignes *avant* chaque correspondance. |
| `-C N` | Affiche les `N` lignes *autour* de chaque correspondance (`-A N -B N`). |

- -> [man page](https://manpages.ubuntu.com/manpages/latest/man1/grep.1.html)

### Avec locate

| Commande | Description |
|----------|-------------|
| `locate` | Trouve rapidement des fichiers en utilisant une base de données pré-indexée du système de fichiers. |
| `sudo updatedb` | mise à jour de la base de données. |

- -> [`locate` man page](https://manpages.ubuntu.com/manpages/latest/man1/locate.1.html)

## Ouvrir un Répertoire dans le Gestionnaire de Fichiers Graphique

| Commande | Description |
|----------|-------------|
| `xdg-open .` | Ouvre le répertoire courant dans le gestionnaire de fichiers graphique par défaut. |
