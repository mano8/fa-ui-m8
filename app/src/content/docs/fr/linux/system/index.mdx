## Raccourcis clavier (Terminal)

| Raccourci           | Description                                                                     |
| :------------------ | :------------------------------------------------------------------------------ |
| **`Ctrl+Alt+T`** | Ouvre un nouveau terminal.                                                      |
| **`Ctrl+C`** | Interrompt le processus actuel (`SIGINT`, un arrêt "poli").                    |
| **`Ctrl+Z`** | Suspend le processus actuel (`SIGTSTP`, peut être repris avec `fg` ou `bg`).   |
| **`Ctrl+D`** | Signale la fin de l'entrée (équivalent à `exit` si le terminal est vide).      |
| **`Ctrl+L`** | Efface l'écran (équivalent à `clear`).                                         |
| **`Ctrl+W`** | Supprime le mot avant le curseur.                                               |
| **`Ctrl+U`** | Supprime toute la ligne avant le curseur.                                       |
| **`Ctrl+R`** | Recherche dans l'historique des commandes.                                      |
| **`!!`** | Répète la dernière commande.                                                    |
| **Historique des commandes**| Utilisez les flèches Haut/Bas pour naviguer dans les commandes précédentes. |

* **`netstat`**:

    | Option | Description                                                                                                                                                                             |
    | :----- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
    | `-t`   | Sélectionne tous les ports TCP.                                                                                                                                                         |
    | `-u`   | Sélectionne tous les ports UDP.                                                                                                                                                         |
    | `-l`   | Affiche les sockets de serveur en écoute (ports TCP et UDP ouverts en état d'écoute).                                                                                                 |
    | `-p`   | Affiche le PID/nom du programme pour les sockets. En d'autres termes, cette option indique qui a ouvert le port TCP ou UDP. Par exemple, sur mon système, Nginx a ouvert le port TCP 80/443, donc `/usr/sbin/nginx` ou son PID sera affiché. |
    | `-n`   | Ne résout pas les noms (évite la recherche DNS, ce qui accélère `netstat` sur les serveurs Linux/Unix occupés).                                                                        |

    ---
    -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/netstat.8.html)

    > `netstat` est majoritairement obsolète. Le remplaçant de `netstat` est `ss`.

* **`ss`**:

    | Option | Description                                      |
    | :----- | :----------------------------------------------- |
    | `-t`   | Affiche uniquement les sockets TCP.              |
    | `-u`   | Affiche uniquement les sockets UDP.              |
    | `-l`   | Affiche les sockets en écoute. Par exemple, le port TCP 22 est ouvert par le serveur SSHD. |
    | `-w`   | Affiche les sockets RAW.                         |
    | `-p`   | Affiche le processus utilisant la socket.        |
    | `-n`   | Ne résout pas les noms de service (c'est-à-dire n'utilise pas DNS). |

    ---
    -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/ss.8.html)

* **`lsof`**:

    | Option | Description                                              |
    | :----- | :------------------------------------------------------- |
    | `-i`   | Sélectionne la liste de tous les fichiers réseau (si aucune IP n'est spécifiée). |
    | `-P`   | Inhibe la conversion des numéros de port en noms de port pour les fichiers réseau. |
    | `-n`   | Inhibe la conversion des numéros de réseau en noms d'hôtes pour les fichiers réseau. |
    | `-U`   | Sélectionne la liste des fichiers de socket de domaine UNIX. |

    ---
    -> [man page](https://manpages.ubuntu.com/manpages/questing/en/man8/lsof.8.html)

### Tâches Cron

Gère les tâches planifiées (tâches cron) pour un utilisateur.

#### Répertoires

Les tâches cron se trouvent dans les répertoires de spool, dans des tables appelées `crontabs`. Leur emplacement varie selon les distributions ; ici, nous nous concentrons sur les systèmes Debian/Ubuntu.

| Emplacement                    | Description                               |
| :----------------------------- | :---------------------------------------- |
| `/etc/crontab`                 | Emplacement des tâches cron pour l'utilisateur `root`. |
| `/var/spool/cron/crontabs`     | Emplacement des tâches cron pour les autres utilisateurs. |

#### Lister les tâches Cron

| Commande                              | Description                                      |
| :------------------------------------ | :----------------------------------------------- |
| `sudo cat /etc/crontab`               | Liste les tâches Cron pour l'utilisateur `root`. |
| `sudo cat /var/spool/cron/crontabs`   | Liste les tâches Cron pour les autres utilisateurs. |
| `crontab -l`                          | Liste toutes les tâches Cron actives pour l'utilisateur actuel. |
| `sudo crontab -u [username] -l`       | Liste toutes les tâches Cron actives par utilisateur. |
| `ls -la /etc/cron.hourly`             | Liste les tâches Cron horaires.                  |
| `ls -la /etc/cron.daily`              | Liste les tâches Cron quotidiennes.              |
| `ls -la /etc/cron.weekly`             | Liste les tâches Cron hebdomadaires.             |
| `ls -la /etc/cron.monthly`            | Liste les tâches Cron mensuelles.                |
| `ls -l /etc/cron.d`                   | Affiche les tâches Cron spécifiques aux logiciels. |

### Gestion des services

Les services système sont gérés par un système d'initialisation (`init system`), souvent `systemd` sur Ubuntu.

* **`systemctl`**: Utilisé pour contrôler et interroger l'état des services système sous `systemd`.

| Commande                                     | Description                                       |
| :------------------------------------------- | :------------------------------------------------ |
| `sudo systemctl reboot`                      | Redémarre le serveur.                             |
| `sudo systemctl poweroff`                    | Éteint le serveur.                                |
| `sudo systemctl rescue`                      | Entre en mode de secours.                         |
| `sudo systemctl start {servicename}`         | Démarre un service.                               |
| `sudo systemctl restart {servicename}`       | Redémarre un service.                             |
| `sudo systemctl stop {servicename}`          | Arrête un service.                                |
| `sudo systemctl status {servicename}`        | Affiche le statut d'un service.                   |
| `sudo systemctl is-active {servicename}`     | Vérifie si un service est actif.                  |
| `sudo systemctl is-enabled {servicename}`    | Vérifie si un service est activé (au démarrage).  |
| `sudo systemctl list-units --type=service`   | Affiche le statut de tous les services.           |
| `sudo systemctl list-units --type=service --state=active` | Affiche le statut de tous les services actifs.    |
| `sudo systemctl enable {servicename}`        | Active un service au démarrage.                   |
| `sudo systemctl disable {servicename}`       | Désactive un service.                             |
| `sudo systemctl mask {servicename}`          | Empêche un service de démarrer.                   |
| `sudo systemctl kill {servicename}`          | Arrête un service.                                |
| `sudo systemctl kill -s 9 {servicename}`     | Force l'arrêt d'un service.                       |
| `sudo systemd-analyze`                       | Analyse les performances de démarrage du système. |
| `sudo systemd-analyze blame`                 | Affiche la ventilation du temps de démarrage du système par service. |

---
-> [`systemctl` man page](https://manpages.ubuntu.com/manpages/questing/en/man1/systemctl.1.html)

### Répertoires système

* **`/run` et `/var/run`** : Répertoires pour les fichiers temporaires créés au démarrage ou par les services.
* **`/etc/default/`** : Répertoire contenant les fichiers de configuration pour les variables utilisées par les scripts d'initialisation (`init.d`).
* **Redémarrage requis** : Un fichier de signalisation `/run/reboot-required` est créé lorsque le système nécessite un redémarrage.
