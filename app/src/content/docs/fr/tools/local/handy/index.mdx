# Utiliser Handy sous windows 11

Dans le cas où Hndy crache sous Windows 11, 
il est nécessaire d'autorizer l'utilisation du micro pour les applications de bureau dans la configuration de Windows. 
Pour cela, il faut aller dans les paramétres > Confidentialité et Sécurité > Microphone.
Dans les paramétres il faut veiller :

1. que l'accés au micro soit activé 
2. que les applications puissent accéder au micro
3. que les applications de bureau puissent acceder au micro

Pour la version 0.7.8 de Handy le programme crashe sans message d'erreur si l'utilisateur n'a pas activé le Micro pour les applications de bureau.
