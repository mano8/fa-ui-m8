En Linux, especialmente en distribuciones basadas en Debian como Ubuntu, la gestión de software se basa principalmente en los **paquetes**. Un paquete es un archivo que contiene todos los ficheros necesarios (programas, bibliotecas, documentación, etc.) para instalar una aplicación o un componente del sistema, así como las instrucciones para su instalación. Las herramientas de gestión de paquetes automatizan la instalación, actualización, configuración y eliminación de este software, manejando de forma inteligente sus dependencias.

---

## APT: La Herramienta de Alto Nivel

**APT** (Advanced Package Tool) es el sistema de gestión de paquetes de alto nivel por excelencia para Debian y sus derivados (Ubuntu, Mint, etc.). Simplifica enormemente la gestión de software al interactuar con herramientas de nivel inferior como `dpkg` y resolver automáticamente las dependencias entre paquetes. La mayoría de las operaciones diarias de gestión de software se realizan con los comandos `apt` (más reciente y fácil de usar) o `apt-get` (históricamente el más utilizado).

### Operaciones APT (apt / apt-get)

| Comando                                    | Descripción                                                                                                                                                                                                                                                                          |
| :----------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sudo apt update`                          | Actualiza el índice de paquetes disponibles desde los repositorios configurados. **Esencial** antes de cualquier instalación o actualización.                                                                                                                                          |
| `sudo apt-get update`                      | (Versión histórica de APT) Actualiza el índice de paquetes disponibles, similar a `apt update`.                                                                                                                                                                                      |
| `sudo apt install <paquete1> [<paquete2> ...]` | Instala uno o más paquetes, incluyendo todas las dependencias necesarias para su correcto funcionamiento.                                                                                                                                                                            |
| `sudo apt-get install <paquete1> [<paquete2> ...]` | (Versión histórica de APT) Instala uno o más paquetes y sus dependencias.                                                                                                                                                                                                           |
| `sudo apt remove <paquete1> [<paquete2> ...]` | Desinstala uno o más paquetes del sistema, manteniendo sus ficheros de configuración.                                                                                                                                                                                                |
| `sudo apt-get remove <paquete1> [<paquete2> ...]` | (Versión histórica de APT) Desinstala uno o más paquetes.                                                                                                                                                                                                                           |
| `sudo apt upgrade`                         | Actualiza todos los paquetes ya instalados a sus versiones más recientes disponibles en los repositorios, sin eliminar ni añadir nuevos paquetes.                                                                                                                                     |
| `sudo apt-get upgrade`                     | (Versión histórica de APT) Actualiza los paquetes instalados.                                                                                                                                                                                                                        |
| `sudo apt-get dist-upgrade`                | Realiza una actualización completa del sistema, gestionando los cambios de dependencias (añadir, eliminar o modificar paquetes) y permitiendo actualizaciones importantes de versión o de kernel.                                                                                     |
| `sudo apt clean`                           | Elimina los ficheros de instalación (`.deb`) descargados que se almacenan en la caché del sistema (`/var/cache/apt/archives/`) y que ya no son necesarios. Libera espacio en disco sin desinstalar software.                                                                        |
| `sudo apt-get clean`                       | (Versión histórica de APT) Elimina los ficheros `.deb` de la caché.                                                                                                                                                                                                                 |

**Páginas de manual asociadas:**

* `apt`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/apt.8.html)
* `apt-get`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/apt-get.8.html)

**Opciones comunes y específicas (para `apt` y `apt-get`):**

| Opción                 | Descripción                                                                                                                             |
| :--------------------- | :-------------------------------------------------------------------------------------------------------------------------------------- |
| `-y` o `--assume-yes`  | Responde automáticamente "sí" a todas las preguntas de confirmación. Úsalo con precaución.                                             |
| `-s` o `--simulate`    | Realiza una simulación de las acciones sin modificar el sistema. Útil para visualizar el impacto de un comando antes de ejecutarlo.    |
| `-u` o `--show-upgraded` | Muestra la lista de paquetes que se actualizarán (usado con `upgrade`).                                                              |
| `-f`                   | Intenta reparar un sistema con dependencias de paquetes rotas (usado con `install` o `remove`).                                        |
| `--purge`              | Usado con `remove`, elimina el paquete **junto con todos sus ficheros de configuración** (excepto los del directorio personal del usuario, `/home`). |
| `--reinstall`          | Usado con `apt install` o `apt-get install`, fuerza la reinstalación de un paquete aunque ya esté en su última versión.               |

### apt-cache: Consultar la Caché de APT

El comando `apt-cache` permite consultar y manipular la caché utilizada por APT. Es particularmente útil para buscar información detallada sobre los paquetes disponibles.

| Comando                      | Descripción                                                                                             |
| :--------------------------- | :-------------------------------------------------------------------------------------------------------- |
| `apt-cache search <expresión>` | Busca una expresión regular (una palabra o frase) dentro de los nombres y descripciones de todos los paquetes disponibles en los repositorios. |
| `apt-cache show <paquete>`   | Muestra información detallada sobre un paquete específico (descripción completa, dependencias, versiones disponibles, etc.). |
| `apt-cache depends <paquete>` | Muestra los paquetes de los que depende el paquete especificado (lo que necesita para funcionar).         |
| `apt-cache rdepends <paquete>` | Muestra los paquetes que dependen del paquete especificado (los que lo necesitan para funcionar).         |
| `apt-cache madison <paquete>` | Indica qué repositorio (fuente de paquete) proporciona el paquete especificado y las versiones disponibles desde ese repositorio. |

**Página de manual asociada:**

* `apt-cache`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/apt-cache.8.html)

**Opciones específicas de `apt-cache search`:**

| Opción        | Descripción                           |
| :------------ | :------------------------------------ |
| `-n` o `--names-only` | Busca solo en los nombres de los paquetes. |

## dpkg: La Herramienta de Bajo Nivel

`dpkg` es la herramienta básica de gestión de paquetes para sistemas Debian y Ubuntu. APT la utiliza para realizar operaciones de instalación, configuración, actualización y eliminación de paquetes. Sin embargo, `dpkg` no gestiona automáticamente las dependencias de paquetes, lo que la hace menos conveniente para el uso diario directo por parte del usuario.

| Comando                  | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dpkg -i <fichero.deb>`  | Permite instalar un paquete directamente desde un fichero `.deb` descargado localmente (`-i` significa `--install`). **Advertencia**: `dpkg` no intentará resolver las dependencias faltantes. Si las dependencias están rotas después de la instalación, es probable que necesites usar `sudo apt install -f` o `sudo apt-get install -f` después para solucionar los problemas de dependencias. |

**Página de manual asociada:**

* `dpkg`: [Ver página de manual](https://manpages.ubuntu.com/manpages/latest/man8/dpkg.8.html)

## Instalación desde el Código Fuente

Además de la instalación a través de gestores de paquetes, también es posible instalar software directamente desde su código fuente. Este método es más complejo y generalmente se prefiere si el software no está disponible en los repositorios, si se requiere una versión específica, o por razones de desarrollo y personalización.

| Paso                         | Comando                                                                                                  | Descripción                                                                                                                                    |
| :--------------------------- | :------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Configuración** | `./configure`                                                                                            | Este script verifica el entorno del sistema para asegurarse de que todas las dependencias de compilación estén presentes y configura el proceso de construcción creando los Makefiles necesarios. |
| **2. Compilación** | `make`                                                                                                   | Este comando inicia el proceso de compilación del código fuente para crear los binarios ejecutables y las bibliotecas del programa.            |
| **3. Instalación** | `sudo make install`                                                                                      | Este comando instala los ficheros compilados (binarios, bibliotecas, etc.) en los directorios estándar del sistema (por ejemplo, `/usr/local/bin`, `/usr/local/lib`). A menudo se requiere `sudo` ya que este paso modifica los directorios del sistema. |
