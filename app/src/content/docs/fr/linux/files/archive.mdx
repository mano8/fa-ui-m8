# Archivage et Compression

---

## Utilisation de `tar`

`tar` est un utilitaire de ligne de commande puissant utilisé pour l'**archivage** de fichiers. Il regroupe plusieurs fichiers et répertoires dans un seul fichier d'archive `.tar`. Souvent, `tar` est combiné avec des outils de compression comme `gzip` ou `bzip2` pour créer des archives compressées telles que `.tar.gz` (ou `.tgz`) ou `.tar.bz2` (ou `.tbz2`).

### Commandes `tar`

| Commande                                                    | Description                                                                                             |
| :---------------------------------------------------------- | :------------------------------------------------------------------------------------------------------ |
| `tar -cvf archive.tar /path/to/directory_or_file`           | **Crée** une archive `.tar` non compressée à partir du contenu de `/path/to/directory_or_file`.         |
| `tar -xvf archive.tar`                                      | **Extrait** une archive `.tar` non compressée dans le répertoire courant.                               |
| `tar -czvf archive.tar.gz /path/to/directory_or_file`       | **Crée** une archive `.tar.gz` compressée à partir du contenu de `/path/to/directory_or_file`.          |
| `tar -xzvf archive.tar.gz`                                  | **Extrait** une archive `.tar.gz` dans le répertoire courant.                                           |
| `tar -xzvf archive.tar.gz -C /path/to/destination_directory/` | **Extrait** une archive `.tar.gz` dans un répertoire de destination spécifique.                         |
| `tar -cjvf archive.tar.bz2 /path/to/source`                 | **Crée** une archive `.tar.bz2` compressée à partir du contenu de `/path/to/directory_or_file`.         |
| `tar -xjvf archive.tar.bz2`                                 | **Extrait** une archive `.tar.bz2` dans le répertoire courant.                                          |
| `tar -tvf archive.tar.gz`                                   | **Liste** le contenu d'une archive `.tar.gz` sans les extraire.                                         |

### Options `tar`

| Option | Description                                      |
| :----- | :----------------------------------------------- |
| `-c`   | **Créer** une nouvelle archive.                  |
| `-x`   | **Extraire** les fichiers d'une archive.         |
| `-t`   | **Lister** le contenu d'une archive.             |
| `-v`   | Mode **verbeux**, affiche les fichiers traités.  |
| `-f`   | Spécifie le **nom de fichier** de l'archive.     |
| `-z`   | Utilise la compression `gzip` (pour les fichiers `.gz`). |
| `-j`   | Utilise la compression `bzip2` (pour les fichiers `.bz2`). |
| `-J`   | Utilise la compression `xz` (pour les fichiers `.xz`). |
| `-C`   | Spécifie le **répertoire de destination** pour l'extraction. |

- -> [man page](https://manpages.ubuntu.com/manpages/latest/man1/tar.1.html)

## Utilisation de `zip` et `unzip`

`zip` et `unzip` sont des utilitaires courants pour la **compression et la décompression** de fichiers et de répertoires. Ils créent des archives `.zip`, qui sont largement utilisées sur différents systèmes d'exploitation.

### Commandes `zip` / `unzip`

| Commande                                    | Description                                                                 |
| :------------------------------------------ | :-------------------------------------------------------------------------- |
| `zip archive.zip file1 file2 directory/`    | **Crée** une nouvelle archive `.zip` contenant les fichiers et répertoires spécifiés. |
| `zip -r archive.zip directory/`             | **Crée** une nouvelle archive `.zip` de manière récursive, incluant tout le contenu d'un répertoire. |
| `zip -u archive.zip file_to_update.txt`     | **Met à jour** une archive `.zip` existante avec un fichier nouveau ou modifié. |
| `zip -d archive.zip file_to_delete.txt`     | **Supprime** un fichier d'une archive `.zip` existante.                     |
| `unzip archive.zip`                         | **Extrait** tous les fichiers de `archive.zip` dans le répertoire courant.  |
| `unzip archive.zip -d /path/to/destination/` | **Extrait** tous les fichiers de `archive.zip` dans un répertoire spécifié. |
| `unzip -l archive.zip`                      | **Liste** le contenu de `archive.zip` sans les extraire.                   |
| `unzip -v archive.zip`                      | **Liste verbeuse** du contenu de `archive.zip`.                             |

### Options `zip` / `unzip`

| Option | Description                                       |
| :----- | :------------------------------------------------ |
| `-r`   | **Récursif** dans les répertoires (pour `zip`).   |
| `-u`   | **Mettre à jour** les entrées existantes dans une archive `.zip`. |
| `-d`   | **Supprimer** des entrées d'une archive `.zip`.   |
| `-l`   | **Lister** le contenu de l'archive (pour `unzip`). |
| `-v`   | Mode **verbeux**, affiche des informations détaillées. |
| `-q`   | Mode **silencieux**, supprime la plupart des sorties. |
| `-x`   | **Exclure** les fichiers spécifiés lors de la compression. |
| `-P`   | **Mot de passe** pour le chiffrement.             |
