Sous Linux, et particulièrement dans les distributions basées sur Debian comme Ubuntu, la gestion des logiciels repose principalement sur les **paquets**. Un paquet est une archive qui contient tous les fichiers nécessaires (programmes, bibliothèques, documentation, etc.) pour installer une application ou un composant système, ainsi que les instructions pour son installation. Les outils de gestion de paquets automatisent l'installation, la mise à jour, la configuration et la suppression de ces logiciels, en gérant de manière intelligente leurs dépendances.

---

## APT : L'Outil de Haut Niveau

**APT** (Advanced Package Tool) est le système de gestion de paquets de haut niveau par excellence pour Debian et ses dérivés (Ubuntu, Mint, etc.). Il simplifie grandement la gestion des logiciels en s'interfaçant avec des outils de plus bas niveau comme `dpkg` et en résolvant automatiquement les dépendances entre les paquets. La majorité des opérations quotidiennes de gestion de logiciels sont effectuées avec les commandes `apt` (plus récente et conviviale) ou `apt-get` (historiquement la plus utilisée).

### Opérations APT (apt / apt-get)

| Commande                                  | Description                                                                                                                                                                                                                           |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `sudo apt update`                         | Met à jour l'index des paquets disponibles à partir des dépôts configurés. **Essentiel** avant toute installation ou mise à niveau.                                                                                                    |
| `sudo apt-get update`                     | (Version historique d'APT) Met à jour l'index des paquets disponibles, similaire à `apt update`.                                                                                                                                     |
| `sudo apt install <paquet1> [<paquet2> ...]` | Installe un ou plusieurs paquets, y compris toutes les dépendances nécessaires à leur bon fonctionnement.                                                                                                                              |
| `sudo apt-get install <paquet1> [<paquet2> ...]` | (Version historique d'APT) Installe un ou plusieurs paquets et leurs dépendances.                                                                                                                                                 |
| `sudo apt remove <paquet1> [<paquet2> ...]` | Désinstalle un ou plusieurs paquets du système, en conservant les fichiers de configuration.                                                                                                                                            |
| `sudo apt-get remove <paquet1> [<paquet2> ...]` | (Version historique d'APT) Désinstalle un ou plusieurs paquets.                                                                                                                                                                       |
| `sudo apt upgrade`                        | Met à jour tous les paquets déjà installés vers leurs versions les plus récentes disponibles dans les dépôts, sans supprimer ni ajouter de nouveaux paquets.                                                                          |
| `sudo apt-get upgrade`                    | (Version historique d'APT) Met à jour les paquets installés.                                                                                                                                                                          |
| `sudo apt-get dist-upgrade`               | Effectue une mise à niveau complète du système, gérant les changements de dépendances (ajout, suppression ou modification de paquets) et permettant les montées de version majeures ou de noyau.                                         |
| `sudo apt clean`                          | Supprime les fichiers d'installation (`.deb`) téléchargés qui sont stockés dans le cache système (`/var/cache/apt/archives/`) et ne sont plus nécessaires. Libère de l'espace disque sans désinstaller de logiciels.                 |
| `sudo apt-get clean`                      | (Version historique d'APT) Supprime les fichiers `.deb` du cache.                                                                                                                                                                     |

**Pages de manuel associées :**

* `apt`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/apt.8.html)
* `apt-get`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/apt-get.8.html)

**Options communes et spécifiques (pour `apt` et `apt-get`) :**

| Option                | Description                                                                                                                              |
| :-------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| `-y` ou `--assume-yes` | Répond automatiquement "oui" à toutes les questions de confirmation. À utiliser avec prudence.                                            |
| `-s` ou `--simulate`  | Effectue une simulation des actions sans rien modifier sur le système. Utile pour visualiser l'impact d'une commande avant de l'exécuter. |
| `-u` ou `--show-upgraded` | Affiche la liste des paquets qui seront mis à jour (utilisé avec `upgrade`).                                                          |
| `-f`                  | Tente de réparer un système dont les dépendances de paquets sont défectueuses (utilisé avec `install` ou `remove`).                    |
| `--purge`             | Utilisé avec `remove`, supprime le paquet **ainsi que tous ses fichiers de configuration** (sauf ceux du répertoire personnel de l'utilisateur, `/home`). |
| `--reinstall`         | Utilisé avec `apt install` ou `apt-get install`, force la réinstallation d'un paquet même s'il est déjà à sa dernière version.          |

### apt-cache : Interroger le Cache APT

La commande `apt-cache` permet de consulter et de manipuler le cache utilisé par APT. Elle est particulièrement utile pour rechercher des informations détaillées sur les paquets disponibles.

| Commande                     | Description                                                                                             |
| :--------------------------- | :-------------------------------------------------------------------------------------------------------- |
| `apt-cache search <expression>` | Recherche une expression régulière (un mot ou une phrase) dans les noms et les descriptions de tous les paquets disponibles dans les dépôts. |
| `apt-cache show <paquet>`    | Affiche des informations détaillées sur un paquet spécifique (description complète, dépendances, versions disponibles, etc.). |
| `apt-cache depends <paquet>` | Affiche les paquets dont dépend le paquet spécifié (ceux dont il a besoin pour fonctionner).              |
| `apt-cache rdepends <paquet>` | Affiche les paquets qui dépendent du paquet spécifié (ceux qui ont besoin de lui pour fonctionner).      |
| `apt-cache madison <paquet>` | Indique quel dépôt (source de paquet) fournit le paquet spécifié et les versions disponibles depuis ce dépôt. |

**Page de manuel associée :**

* `apt-cache`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/apt-cache.8.html)

**Options spécifiques à `apt-cache search` :**

| Option        | Description                                     |
| :------------ | :---------------------------------------------- |
| `-n` ou `--names-only` | Ne recherche que dans les noms des paquets. |

## dpkg : L'Outil de Bas Niveau

`dpkg` est l'outil de gestion de paquets de base pour les systèmes Debian et Ubuntu. Il est utilisé par APT pour effectuer les opérations d'installation, de configuration, de mise à niveau et de suppression de paquets. Cependant, `dpkg` ne gère pas automatiquement les dépendances de paquets, ce qui le rend moins pratique pour une utilisation quotidienne directe par l'utilisateur.

| Commande                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                           |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `dpkg -i <fichier.deb>`  | Permet d'installer un paquet directement à partir d'un fichier `.deb` téléchargé localement (`-i` signifie `--install`). **Attention** : `dpkg` n'essaie pas de résoudre les dépendances manquantes. Si des dépendances sont cassées après l'installation, vous devrez probablement utiliser `sudo apt install -f` ou `sudo apt-get install -f` par la suite pour corriger les problèmes de dépendances. |

**Page de manuel associée :**

* `dpkg`: [Voir man page](https://manpages.ubuntu.com/manpages/latest/man8/dpkg.8.html)

## Installation à partir des Sources

En complément de l'installation via les gestionnaires de paquets, il est également possible d'installer des logiciels directement à partir de leur code source. Cette méthode est plus complexe et est généralement privilégiée si le logiciel n'est pas disponible dans les dépôts, si une version spécifique est requise, ou pour des raisons de développement et de personnalisation.

| Étape                          | Commande                                                                                                | Description                                                                                                                            |
| :----------------------------- | :------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Configuration** | `./configure`                                                                                           | Ce script vérifie l'environnement système pour s'assurer que toutes les dépendances de compilation sont présentes et configure le processus de construction en créant les Makefiles nécessaires. |
| **2. Compilation** | `make`                                                                                                  | Cette commande lance le processus de compilation du code source pour créer les fichiers binaires exécutables et les bibliothèques du programme. |
| **3. Installation** | `sudo make install`                                                                                     | Cette commande installe les fichiers compilés (binaires, bibliothèques, etc.) dans les répertoires standards du système (par exemple, `/usr/local/bin`, `/usr/local/lib`). L'utilisation de `sudo` est souvent requise car cette étape modifie les répertoires système. |
